# Reporte privado de seguridad

No publiques vulnerabilidades, datos personales o credenciales en incidencias públicas.
Usa el reporte privado de vulnerabilidades de GitHub si está disponible; en caso contrario,
contacta de forma privada al propietario @Dreamcoder08 antes de enviar detalles sensibles.

La versión 0.1 es una base de desarrollo con datos sintéticos. No está aprobada para
producción ni sustituye una evaluación independiente antes del piloto con datos reales.

Revisamos límites de asociación, roles, sesiones, archivos, exportaciones, sincronización,
procesos en segundo plano, dependencias y cadena de entrega. Los datos locales de un
dispositivo desbloqueado o comprometido siguen siendo accesibles al usuario del dispositivo.

Los avisos críticos o con explotación conocida se evalúan en 24 horas; objetivo de parche
en 72 horas, con contención inmediata si existe exposición. Estos son objetivos operativos,
no una garantía de servicio. Toda excepción requiere responsable, causa, control compensatorio
y fecha de vencimiento. No se permite una excepción permanente basada solo en severidad.
