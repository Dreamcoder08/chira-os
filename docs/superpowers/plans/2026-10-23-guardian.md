# CHIRA OS — approved implementation plan

Private repository Dreamcoder08/chira-os. Modular hexagonal TypeScript monorepo;
React/Vite PWA, Fastify API, PostgreSQL/PostGIS, Drizzle, Better Auth password-only,
pg-boss worker, private local files with an S3 adapter. No deployment or cloud purchases.

## Deliverables

1. Reproducible workspace, CI, dependency and architecture controls.
2. Identity, association memberships, assigned parcels and forced tenant RLS.
3. Offline inspections, photographs, idempotent sync, conflicts and coordinator review.
4. Private file access, exports, audit, constrained worker and recovery scripts.
5. Domain/integration/browser verification; Archify architecture and sync diagrams.
6. Documentation, independent security review and private GitHub publication.

## Acceptance

Clean checkout starts locally. A technician downloads assigned parcels, captures an
inspection and photograph offline, reopens, synchronizes and a coordinator reviews it.
Cross-tenant access fails through API, SQL RLS, files, exports and jobs. Replayed
operations do not duplicate writes. Revoked sessions fail after reconnection.
CI runs typecheck, lint, architecture checks, formatting, unit/integration/E2E tests,
build, security scans and reproducible diagram validation.

## Security constraints

Individually assigned locked phones, minimal local data, no browser-readable tokens,
explicit deletion at logout. Remote revocation cannot erase disconnected devices.
No HTML inspection content, SVG uploads, public buckets, public dev servers,
automatic sensitive merges or unattended installers. Same-origin cookies and CSRF.
No diagnosis, Water, Trade, sensors or live satellite processing.
